## 💡 نبذة عن المشروع والهدف منه

يعاني محللو البيانات، والمطورون، ورواد الأعمال، والباحثون من استهلاك ما يصل إلى **80% من أوقاتهم** في عمليات تنظيف البيانات اليدوية الروتينية قبل التمكن من الاستفادة منها في التحليلات أو بناء نماذج الذكاء الاصطناعي.

جاءت منصة **DataFixer** لتكون الحل الشامل والذكي؛ حيث توفر واجهة ويب تفاعلية بنمط تطبيقات الـ **SaaS**، تُمكّن أي مستخدم من رفع ملفات البيانات المعطوبة أو غير المنظمة، واكتشاف كافة المشكلات والعيوب الهيكلية والدلالية فيها بضغطة زر، وإصلاحها بمرونة فائقة مع إمكانية التراجع الكامل (`Undo / Redo`)، ثم تصدير البيانات النظيفة وتوليد تقارير تدقيق مهنية بصيغتي **HTML** و **PDF**.

## 🔍 المشكلات التي يعالجها التطبيق

يقوم المحرك التحليلي لـ **DataFixer** بفحص واكتشاف **11 عيباً هيكلياً ودلالياً** في مجموعات البيانات:

| # | نوع المشكلة | آلية الاكتشاف والتصنيف |
|---|-------------|------------------------|
| **1** | **القيم المفقودة أو الفارغة (Missing Values)** | حصر دقيق للخلايا الفارغة (`None`, `NaN`, نصوص الفراغ، والرموز المعطوبة مثل `N/A`, `null`, `-`). |
| **2** | **الصفوف المكررة (Duplicate Rows)** | اكتشاف الصفوف المتطابقة كلياً أو جزئياً استناداً إلى كامل الجدول أو أعمدة مخصصة. |
| **3** | **أسماء الأعمدة المكررة (Duplicate Headers)** | كشف تكرار التسميات أو تطابقها عند تجاهل حالة الأحرف لمنع التعارض الحسابي. |
| **4** | **أنواع البيانات غير الصحيحة (Type Inconsistencies)** | كشف الأرقام والتواريخ المسجلة كنصوص، والرموز المالية (`$`, `€`, `%`) المدمجة مع الأرقام. |
| **5** | **المسافات الزائدة في النصوص (Excess Whitespace)** | كشف المسافات في بداية ونهاية النصوص أو المسافات المتعددة المتتالية داخل الكلمات. |
| **6** | **تفاوت حالة الأحرف (Case Inconsistency)** | كشف الاختلاف بين كتابة نفس القيمة بحروف كبيرة وصغيرة (مثل: `Active` مقابل `active`). |
| **7** | **التواريخ غير الصالحة أو المتباينة (Date Flaws)** | رصد التواريخ المعطوبة أو المكتوبة بصيغ متعددة متضاربة داخل نفس العمود. |
| **8** | **الأعمدة الفارغة بالكامل (Empty Columns)** | تحديد الأعمدة الخالية 100% من البيانات لاقتراح حذفها وتخفيف عبء المعالجة. |
| **9** | **الصفوف الفارغة بالكامل (Empty Rows)** | كشف السجلات التي لا تحتوي على أي قيمة مفيدة. |
| **10** | **القيم الشاذة في الأعمدة التصنيفية (Categorical Anomalies)** | رصد الأخطاء الإملائية والتباينات النادرة في التصنيفات. |
| **11** | **القيم الرقمية الشاذة (Numerical Outliers)** | فحص إحصائي معمق عبر معايير المدى الربيعي (**IQR**) والانحراف المعياري (**Z-Score**). |

## 🚀 الميزات والوظائف الأساسية

- **مؤشر جودة البيانات الشفاف (Data Quality Score: 0 - 100):** مؤشر موضوعي قابل للتفسير يعتمد على 4 ركائز: الاكتمال (Completeness)، الفرادة (Uniqueness)، الصحة (Validity)، والاتساق (Consistency).
- **أدوات تنظيف معيارية مستقلة (Modular Cleaning Engine):**
  - **القيم المفقودة:** حذف الصفوف أو تعويضها بالمتوسط الحسابي (Mean)، الوسيط (Median)، المنوال (Mode)، أو قيمة مخصصة.
  - **التكرارات:** خيارات مرنة لحذف كل التكرارات، أو الاحتفاظ بالنسخة الأولى أو الأخيرة مع تحديد الأعمدة المستهدفة.
  - **تنظيف النصوص:** إزالة المسافات، توحيد حالة الأحرف (lower, UPPER, Title)، والبحث والاستبدال بالرموز أو بالتعابير النمطية (Regex).
  - **هيكلية الأعمدة:** توحيد التسميات القياسية إلى `snake_case`، حذف الأعمدة، إعادة التسمية، وتحويل أنواع البيانات بأمان.
  - **التواريخ والشواذ:** توحيد صيغ التواريخ إلى `YYYY-MM-DD`، وتحجيم الشواذ (Clipping/Winsorizing) أو استبدالها دون حذف صامت.
- **نظام التراجع والتقدم الكامل (Undo / Redo):** مكدس آمن يتيح الرجوع خطوة بخطوة عن أي عملية تنظيف، مع زر للاستعادة الكاملة للملف الأصلي.
- **عرض كافة صفوف الجداول وتصفحها (Pagination):** إمكانية استعراض جميع الصفوف بلا قيود، مع خيارات مرنة لتقسيم الصفحات (25, 50, 100, 250 أو عرض الكل).
- **دعم كامل للغة العربية والواجهة (RTL):** محاذاة شاملة من اليمين إلى اليسار للنصوص، والقوائم الجانبية، والبطاقات الإحصائية، والأزرار.
- **رسوم بيانية تفاعلية باستخدام Plotly:** توزيع القيم المفقودة، نسب التكرارات، نسب أنواع البيانات، ومدرج تكراري/صندوقي للأعمدة الرقمية.
- **تصدير وتقارير احترافية:**
  - تصدير البيانات المنظفة إلى: **CSV** (ترميز `utf-8-sig` لدعم اللغة العربية في Excel)، **Excel (.xlsx)**، و **JSON**.
  - توليد تقرير تدقيق الجودة الشامل (Audit Report) كصفحة **HTML** تفاعلية، أو وثيقة **PDF** رسمية تدعم اللغة العربية بالكامل.

| التقنية | الدور البرمجي في المشروع |
|---|---|

| **uv** | مدير الحزم والبيئات الافتراضية فائق السرعة والموثوقية لإدارة المشروع حصرياً. |
| **Streamlit** | إطار عمل بناء واجهة المستخدم التفاعلية المتجاوبة وتطبيقات الـ SaaS. |

| **Polars** | محرك معالجة البيانات الضخمة والأداء العالي في الذاكرة. |
| **OpenPyXL** | قراءة وكتابة ومعالجة ملفات Microsoft Excel متعددة الأوراق. |
| **Pydantic** | التحقق من صحة هياكل البيانات، ومخططات الجودة، وتوصيف الإعدادات. |
| **Plotly** | إنشاء الرسوم البيانية التفاعلية المتقدمة وتصور توزيعات الجودة. |

| **Ruff** | الفاحص والمنسق البرمجي فائق السرعة للحفاظ على نظافة الكود والمعايير القياسية. |

## ⚙️ طريقة إعداد المشروع وتشغيله

### 1. استنساخ المشروع
```bash
git clone https://github.com/Yahya-Studio/DataFixer.git
cd DataFixer
```

### 2. تثبيت الاعتماديات وتجهيز البيئة باستخدام `uv`
```bash
uv sync
```

### 3. تشغيل التطبيق محلياً
يمكنك تشغيل التطبيق مباشرة عبر الأمر:
```bash
uv run streamlit run app.py
```
أو عبر المشغل المباشر:
```bash
uv run python main.py
```
سيعمل التطبيق تلقائياً في متصفحك على الرابط المحلي: `http://localhost:8501`.

## 📖 دليل الاستخدام المفصل

```
[1. Upload Dataset] ──► [2. Data Analysis] ──► [3. Data Cleaning] ──► [4. History & Diff] ──► [5. Export & Reports]
     رفع الملف                تحليل الجودة                 التنظيف والتصحيح             المقارنة والتراجع           تصدير البيانات والتقرير
```

1. **رفع ملف البيانات (Upload Dataset):**
   - اسحب ملفك بصيغة `CSV` أو `Excel` أو `JSON` وأفلته في واجهة الرفع.
   - في حال كان الملف من نوع Excel يحتوي على أكثر من ورقة عمل، سيظهر خيار لتحديد ورقة العمل المطلوبة.
   - انقر على **"قراءة وتحليل الملف"** للمتابعة.

2. **تحليل الجودة ومستكشف البيانات (Data Analysis):**
   - استعرض مؤشر الجودة الكلي والركائز الأربعة (الاكتمال، الفرادة، الصحة، الاتساق).
   - اطلع على قائمة المشكلات الـ 11 المكتشفة مع التوصية المخصصة لكل مشكلة.
   - استخدم مستكشف الأعمدة للاطلاع على الإحصائيات الوصفية وتوزيعات القيم الرقمية والنصية.

3. **تنظيف وتصحيح البيانات (Data Cleaning):**
   - تنقل بين تبويبات التنظيف المخصصة (القيم المفقودة، التكرارات، النصوص، الأعمدة، والتواريخ والأرقام).
   - حدد الإجراء المطلوب وعاين عدد الصفوف أو الخلايا المتأثرة قبل التطبيق.
   - استخدم جدول المعاينة أسفل الصفحة لتصفح كافة صفوف الجدول وملاحظة التغييرات الفورية.

4. **سجل العمليات والمقارنة (Cleaning History):**
   - استعرض شريط التاريخ وسجل التدقيق الزمني لكافة العمليات المنفذة.
   - استخدم زري **تراجع (Undo)** و **إعادة (Redo)** لتجربة خياراتك بأمان تام.
   - قارن بين البيانات الأصلية والبيانات المعالجة جنباً إلى جنب.

5. **التقارير والتصدير (Reports & Export):**
   - نزّل نسختك المنظفة بالصيغة التي تفضلها: **CSV** أو **Excel** أو **JSON**.
   - حمّل تقرير التدقيق الشامل بصيغة **HTML** أو **PDF** لمشاركته مع فريق العمل أو العملاء.

## 📁 صيغ الملفات المدعومة

- **ملفات CSV (`.csv`):** كشف آلي للترميزات العربية والإنجليزية والفواصل المختلفة.
- **ملفات Excel الحديثة (`.xlsx`):** دعم استخراج الجداول واختيار أوراق العمل.
- **ملفات Excel القديمة (`.xls`):** دعم التوافقية مع المصنفات القديمة.
- **ملفات JSON (`.json`):** قراءة مصفوفات السجلات (Records) وتطبيع البيانات الهرمية.

## 🧪 الاختبارات والتحقق من جودة الكود

المشروع مزود بمنظومة اختبارات تغطي محرك التنظيف، والتحليل، ومؤشر الجودة، وإدارة الحالات، وتصدير التقارير:

```bash
# تشغيل جميع الاختبارات المؤتمتة
uv run pytest -v
```

فحص الكود والتحقق من المعايير القياسية والتنسيق باستخدام `Ruff`:
```bash
# فحص الكود البرمجي
uv run ruff check .

# التحقق من تنسيق الكود
uv run ruff format --check .
```
